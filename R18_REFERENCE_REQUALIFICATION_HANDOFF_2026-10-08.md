After the positive smoke, prove that changing a source-locked file while retaining the new sidecars *still* blocks Reference. Do this only in an isolated copy, never by changing the release checkout:

```bash

repo="$PWD"
iso=/absolute/path/to/real-sacd.iso
scratch="$(mktemp -d)"
mkdir -p "$scratch/repo" "$scratch/output"
tar --exclude='./target' -cf - . | tar -C "$scratch/repo" -xf -
printf '\n// negative release-gate smoke only\n' >> "$scratch/repo/src/convert/pipeline/stages.rs"
(
  cd "$scratch/repo"
  if cargo test --test reference_qualification_freshness; then
    echo 'ERROR: altered locked source passed freshness gate' >&2
    exit 1
  fi
  if cargo run --release -- convert "$iso" --track 1 --area stereo \
       --dsd-path reference --format flac --output "$scratch/output" \
       > "$scratch/negative.log" 2>&1; then
    echo 'ERROR: changed Reference runtime was accepted' >&2
    exit 1
  fi
  grep -q 'Reference production promotion is inactive' "$scratch/negative.log" || {
    cat "$scratch/negative.log" >&2
    echo 'ERROR: conversion failed for a reason other than Reference refusal' >&2
    exit 1
  }
  test -z "$(find "$scratch/output" -type f -print -quit)" || {
    echo 'ERROR: negative conversion published an output file' >&2
    exit 1
  }
)
# Remove $scratch after reviewing the negative.log evidence.
```

A green negative freshness gate means the source drift was **detected as a failure** as expected; it does not mean the altered copy became qualified. Verify a qualified positive conversion and the negative runtime mismatch before calling the release accepted. Keep the `TONEPOET_DSD_REFERENCE_UNQUALIFIED_OVERRIDE` variable unset for every acceptance run.
