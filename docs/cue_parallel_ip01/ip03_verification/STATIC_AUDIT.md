# IP-03 scoped independent static audit

**Date:** October 24, 2026. **Disposition:** `implemented-unqualified` / no S3 activation. Source IP-03 changes are confined to `src/convert/pipeline/track_executor.rs`; current data and repeated file-by-file checks are in `SOURCE_DIFF.json` and `verify_static_ip03.py`.

- **Existing resource authority:** `ToolConcurrencyLimits`'s shared `Arc<Semaphore>` instances are reused. The new in-flight S3 slot is stored on that same shared limits object. No per-album control, weighted RAM scheduler or new process supervision.
- **Two-child costing:** `try_acquire_many_owned(2)` reserves both FFmpeg tokens in one nonblocking call. FFmpeg+SoX reserves SoX (1) and FFmpeg (1), immediately releasing SoX/slot if FFmpeg is unavailable. No acquisition awaits, so incomplete pairs cannot deadlock.
- **Lifetime and fallback:** `run_cue_s3_pipeline_if_admitted` binds the RAII owner over a direct `runner.run_pipeline(...)`. A refusal is `Declined` before any spawn; after the call begins, `Executed(Err(...))` propagates the failed attempt. Closure and cancellation are errors. Old S1 keeps its original independent path.
- **Limits and bounds:** maximum two admitted global S3 streams, reduced to one on one- or two-FFmpeg hosts. Each S3 stream uses the original supervised OS pipe, per-command bounded log tail buffers, no full PCM carriers; two S3 tool children per admitted worker. Small, fixed resource high-water proportional to N, not track count.
- **Legacy coexistence qualification:** S1's segmented FFmpeg/FFmpeg pair still undercounts actual children as one FFmpeg token; tests make that visible, and the whole-process concurrency bound cannot be generalized to existing S1. Do not interpret S3 cost=2 as repairing S1. A host measurement must determine whether conservative S3 denial under legacy load or a *narrow measured* S1 correction is required before admission.
- **Tool contract:** Existing `ToolRunner::run_pipeline` is Unix-only and already supervises both endpoints through a shared cancellation token and child containment. No new child spawn implementation is introduced; two real supervised-process tests were authored for cancellation/reaping and early consumer exit, plus slow consumer test. All are NOT RUN here.
- **Source identity:** No changes to IP-02 FLAC reader or its STREAMINFO contract, CUE boundaries, metadata/artwork, ReplayGain, transport S1, planner, tool interface, logging, publication, or user-visible flags. No Rust build/test result claimed.
- **Independent native probe:** 16 deterministic full-byte comparisons across 1- and 2-pair FFmpeg/FFmpeg pipes. PASS for these generated fixtures on this authoring host. Pipe 65,536 bytes; peak sampled parent+children FDs 15 and 26, total RSS 168,840 and 232,944 KiB respectively. These are observations, not rigorous upper bounds of Rust or of arbitrary hosts.

**Additional executed regressions:** Original IP-01 offline Python tests PASS 15/15. The six-hunk production patch applies cleanly to the pristine archive and a second forward application is correctly refused; byte SHA of patched scratch equals authored source. See `LEGACY_IP01_PYTHON_TEST_OUTPUT.txt` and `PATCH_CHECK.txt`.
