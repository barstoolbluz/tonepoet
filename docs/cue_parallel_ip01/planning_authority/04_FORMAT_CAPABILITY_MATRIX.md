# Source and destination qualification matrix

**Scope discipline:** "current CUE candidate" means the source-detection/queue/materializer code can route an actually admitted CUE and discover the referenced audio, not that arbitrary audio recognized by upstream FFmpeg has been validated in TonePoet. "Structural S1" means `CueStreamSegment` can be created when exact PCM, known channels and a valid sample count are **actually** observed; planner admission may still reject it. "S3 qualified" means tested independent seek + exact segment decode + semantics; **no format is S3-qualified at this planning date**.

**Source ground truth:** `src/convert/pipeline/stages.rs:608-665` detects CUE vs special disc before single-file; `src/convert/pipeline/materializer_cue.rs:798-1110` selects CUE and resolves input; `:491-690` creates `CueStreamSegment` or staged carriers; `:1867-1935` probes; `:2183-2310` maps exact `duration_ts`; `src/convert/pipeline/types.rs:2433-2555` classifies coding and bit depth; `src/convert/pipeline/track_executor.rs:1355-1539` admits a **specific output plan**. For input files under one authored CUE, range positions are integer decoded PCM sample indices derived from INDEX 01 ticks (75/sec), `src/convert/pipeline/materializer_cue.rs:2335-2492`.

### Output qualification is separate from input seeking

- **Pilot:** FLAC output with `RateTarget::Source`, `BitDepthTarget::Source`, no intentional DSP. Actual command is the **existing single-command planner result** (`track_executor.rs:1355-1539`), not a new `flac` writer. Test both permissible SoX and FFmpeg plan shapes; reject unqualified variants. The original FFprobe depth/sample validator and publisher still run (`stages.rs:2436-2575`, `:27544-28100`).
- **Subsequent outputs:** WAV/RF64, AIFF, WavPack, ALAC, and supported lossy encoders may in principle consume a correct range PCM stream. They are **not** qualified merely because FLAC *input* seek is proven. Planner transport, float/int carrier, metadata/artwork, gain, dither and intermediate/output verification must pass separately. An output-format list in `src/convert/formats.rs:23-90` is not an admission list.
- **DSP shapes:** resampling, HDCD, pre-emphasis, de-emphasis, DC correction, true-peak, dither, source-sensitive normalization and DSD reconstruction all retain planner ownership. Stateful/album-scope plans stay on existing route until a separate qualification packet proves correct filter state and observation. `track_executor.rs:1355-1539` is the authoritative first gate.
- **Input seeking vs output encoding:** sample-accurate seek is on the decoder side; output parallelism is on independent authorized encoder processes; both must be validated and globally resource-admitted. Neither proof implies the other.

### Required adapter promotion record

Before a format becomes an S3-admitted source, enter in `CONFORMANCE_MATRIX.md` the precise container subtype/tool version, `position_domain`, exact authoritative frame count and channel/depth, seek operation and priming contract, integer sample trimming behavior, first/last sample & EOF proof, metadata/album context, global resource weight, supported destination plan shapes, fixture hashes/platforms, failure policy, benchmark crossover, and **full-source commit SHA**. An 'unknown' cell is rejection/fallback, not optimistic eligibility. Platform-specific qualifications do not magically extend to untested platforms.

### R2 portability qualification boundary

The source has a platform-level transport constraint separate from codec support: `RealToolRunner::run_pipeline` is Unix-only (`src/convert/pipeline/tool.rs:2170-2372`), as is today's segmented stream transport (`:2374-2787`). **No S3 promotion on non-Unix** unless a separate, actually implemented and tested supervised pipe runner is supplied. The initial pilot is Unix-only. Never generalize a successful Windows `ffmpeg -ss` test to working TonePoet pipeline orchestration. This gate occurs *before* any range process is launched and does not change the legacy path.
