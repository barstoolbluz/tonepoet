# TonePoet R20 — RF64 read-path corrective and HDCD dither regression handoff

Date: 2026-10-15. Input: `TonePoet_LOGGING_R20_hdcd_dither_rf64_2026-10-15.tar.gz` (SHA-256 `bdc4d0947119a7bcf572422b03b65795aafdfcb7a2f4c6ec45e882565cc7155e`) and `BRIEF_R20_hdcd_dither_revert_and_rf64_2026-10-15.md`.

## Result and scope

**RF64 / issue #62:** New `src/tui/rf64_metadata.rs` offers a read-only, bounded metadata view for genuine RF64/WAVE carriers when Lofty 0.21 refuses the magic. It scans and skips `data` by its 64-bit `ds64` size, preserves existing non-audio RIFF chunks including `LIST/INFO` and ID3 artwork, reconstitutes a compact RIFF view entirely in memory, and passes it to the **existing Lofty reader**. Neither source nor audio samples are modified or transcoded. Source format selection uses the file's RF64 magic, not `.wav`/`.rf64` extension. Individual retained chunk limit 32 MiB, total view limit 64 MiB; unreasonable/corrupt chunk geometry is refused with an error, not allocated. Normal Lofty reads still take the original fast path.

Integration surfaces:

- `src/tui/probe.rs`: Browse/metadata pane, merged metadata editor, lazy artwork bytes. Exports small `pub(crate)` methods to allow existing typed errors on other formats.
- `src/convert/pipeline/materializer_single.rs`: **critical** conversion file naming, metadata warning truthfulness, and IndividualFiles viability. This is the route that caused `01 - Track 01.flac` despite valid tags.
- `src/convert/pipeline/materializer_cue.rs`, `src/convert/queue_expansion.rs`: CUE-image album metadata and embedded-CUESHEET reads.
- `docs/OUTSTANDING_ISSUES.md`: #62 implementation note; no premature verified closure and no changes to #70–#76 status.

**HDCD dither revert:** A close source trace of all three toggle routes found the existing ownership logic already calls `recompute_auto_hdcd` → `apply_auto_dither`. Without a user or preset override, HDCD Off should restore the ordinary automatic 16→16 policy (`None`). A legitimate explicit TPDF remains; independently active CD de-emphasis still calls for TPDF. In the absence of a reproduced failing state, **no speculative production-state change was made**, since clearing `dither_overridden` would erase intentional user selections. New regression tests cover keyboard next/previous and mouse Off, dither manual None/TPDF/Shibata preservation, independent de-emphasis, and automatic TPDF restored from a preset. The original field observation remains **unexplained and not certified fixed** until these tests and a user-state reproduction are run.
